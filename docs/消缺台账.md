### D1（P1、已修于第 40 轮）声明名位置与关键字/类型别名的同词冲突

- **修复记录（第 40 轮）**：translate() 第 2 步查表改绑句法位置：a. 前一词元映射值∈{const,var,fn}（含 ASCII 直通形）时当前词强制转码；b. 母语词已被工程 intern 为标识符时，除 `:` 右侧类型标注位外引用处标识符优先；点分别名链（标准库→std）在第 1 步先行、不受影响。回归：translate.zig 新测试（声明/引用/类型三面全等词）+ 探针 `常数 文本 = 嵌入文件("note.txt")` run EXIT=0。

- **复现**：`常数 文本 = 嵌入文件("note.txt");` → 生成 `const []const u8 = @embedFile("note.txt");`（非法 Zig，

## 结构性风险（写包/改码守则）

- **R1** matchDiag 取**首个 pattern 子串命中**即返回：新词条若与既有词条互为子串会被遮蔽，入包前先做包含性核对
  （例：`failed opening "` 与 `unable to load "` 不冲突故可共存）。
- **R2** diagnostics 行 `键 = 模式|译文|提示` 以 `|` 分段：任何一段出现裸 `|` 都会破坏解析；多词族用 `/` 分隔。
- **R3** 方言侧键纯中文守则（用户 2026-10 指示）：`[keywords]/[aliases]` 左键禁含任何 ASCII 字母，
  守卫测试在 translate.zig 遍历全键断言；旧混合形 `opaque类型`/`类型of` 已于第 38 轮更名为

- **R7f**（第 48 轮新增守则）Zig 0.17 API 断代速查：`std.fs.cwd()`/`std.io.getStdOut()`/`argsAlloc`/managed `ArrayList.init` 已移除；

  49 轮增补：`std.Io.Limit` 是 `enum(usize)` **带载荷枚举**，`.limited = n` 结构体初始化形非法（`does not support struct initialization`），
  须 `Io.Limit.limited(n)` 构造。
  50 轮增补：0.17 error set 为值枚举，但 `catch |e| switch (e)` 的 case 与错误值数组元素**都必须 `error.Foo` 显式形**，

  52 轮增补：① `std.json.Stringify.Options` 无 `pretty` 字段→用 `whitespace` 枚举（`.minified/.indent_1..4/.indent_8/.indent_tab`）；

  ⑤ **借用 vs 拥有**：返回源串子串的 ArrayList（如 `extractEmbedPathsForms`）只能 `deinit` 本体、逐项 free 会崩溃。
