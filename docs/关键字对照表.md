# 中文关键字对照表

本表列出内置中文语言包（`src/lang/packs/中文.txt`）的词法映射。方言只替换词法单元，语法骨架（`()` `{}` `[]` `!T` `?T` `@import` 多行字符串等）保持 ASCII Zig 原生写法。

> 表中未列出的 Zig 语法词（`nop`、非标度宽整型 `i4`/`u29` 等、`f80`，以及 `c_int`/`c_char` 等 C ABI 名）按「表中无则原样透传」处理，可在语言包迭代补全，不影响编译。常用定宽类型词须成族覆盖（D45）：否则纯母语门对同词族「已映射的拦、未映射的放」，英文 `i32` 这类 AI 源码高频形会无声通过。

> 数学内建方言词（第 146–147 轮）与下方 `标准库.数学.*` 成员**同术语**：裸调用 `平方根(甲)` 走内建 `@sqrt`，带前缀 `标准库.数学.平方根(甲)` 走 `std.math.sqrt`，两者互不劫持。`@pow` 经编译器坐实在 Zig 0.17 不存在，故无裸「幂」方言词——幂运算走 `标准库.数学.幂`（`std.math.pow`）。对数/指数族已按底数写明（自然对数=@log、常用对数=@log10、二进制对数=@log2），避免「log 是 ln 还是 log10」歧义。
> 余除/位运算族（第 149 轮）同经 build-obj 坐实存在：取余/除法写明「向下/截断」避免 @mod（随除数符号）与 @rem（随被除数符号）、@divFloor 与 @divTrunc 语义歧义（承 146 下取整/截断取整口径）；`@fabs` 坐实不存在（绝对值统一走 `@abs`）、`@mulAdd` 需前导类型参非自然裸调形，均未登记。
> 第 150 轮收官审计：对 Zig 0.17 内建全集逐族 build-obj 分档——发现 `@divExact`（精确整除、除不尽即 panic）系 149 除法族漏登的第 5 个成员，与向下/截断除法并立；新增类型元/值转字符串新域（类型大小=@sizeOf、对齐大小=@alignOf、位大小=@bitSizeOf、类型名=@typeName、标签名=@tagName、错误名=@errorName，arg 为类型或返回字符串）。`@memberCount`/`@byteOffsetOf` 坐实 0.17 不存在（走 std.meta），转型族（@as/@intCast…）需已知结果类型、非自然裸值形，`@addWithOverflow` 返 {值,溢出} 结构体——均未登记。

## 标准库路径别名（点分链贪心最长匹配）

覆盖 `std.zig` 全部顶层 `pub` 名（第 141 轮全量扩充），按类型分组。模块级别名天然支持成员全链：
写 `标准库.调试.print(...)` → `std.debug.print(...)`（链止于 ASCII 成员、成员原样保留）。
**未列出的成员名会逐段回退**（`标准库` → `std`，其余 ASCII 段原样透传），故 `标准库.mem.eql`、
`标准库.ArrayList` 等英文原名照旧可用——中文别名是增益路径、非唯一路径。键的成员段须纯中文
（ASCII 段会被词法器切成 `ascii_word`、别名链永不命中）。

## 标识符转码

未命中关键字表与别名表的母语单词按用户标识符处理，映射为稳定 ASCII 名 `z_<编号>`（按首次出现顺序）。符号表持久化于 `.zzc/symbols.txt`，保证同一工程内跨文件、跨会话一致；`eject` 时母语原名以注释形式保留在导出文件头部。
