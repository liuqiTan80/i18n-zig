# zzc 中文繁体字形补充层（叠加进基包 zh，非独立可选包）
#
# ---- 注册头指令（供 build.zig 自动发现，R9续②/③）----
# @overlay-of zh
# @order 10
# @display 繁体字形
# @aliases 繁体,繁體,繁体中文,繁體中文,繁体字,繁體字,正体字,正體字
#
# 语义：为基包 zh 的简体关键字并集登记等价繁体字形，使同一份 zh 包同时接受简体与繁体词形
# （如 常數 与 常数 都译成 const）。这里是纯键并集——每个繁体键与基包其简体孪生键映射同一
# ASCII 值、互不覆盖，不改变简体重写行为（diagnostics/whitelist 亦按并集/后写规则合并）。
# 键仍守 R3：全为纯中文（繁体汉字），不含 ASCII 字母。
#
# 第 332 轮 D191：本层从「7 条常见字形」扩到全量字形覆盖——简体基包的 113 关键字 / 204 路径
# 别名逐条经 s2t（纯字形，不改用语）转出，同形者跳过（基包已含）。此前 `變量`/`對於`/`整數`
# 等字形一律不被词法识别，繁体用户实际只能写简体或那 7 个词。
#
# 只到 keywords/aliases 为止，**不收 [diagnostics]**：叠加层是按 pattern 后写覆盖进基包的，
# 一旦把 93 条译文转成繁体，简体默认路径的报错也会跟着变繁体（真跑与 demos-smoke 当场抓到
# 「不可变常量被重新赋值」不再命中）。诊断译文仍以基包简体为唯一来源。
